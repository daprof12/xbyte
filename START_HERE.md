## 🎓 What You're Building

**Xbyte Wallet** is a hybrid custodial/non-custodial cryptocurrency wallet with:

### **User Side:**
- Multi-chain support (BTC, ETH, SOL, BNB, TRON)
- Send, receive, swap, buy crypto
- QR code generation
- Transaction history
- 2FA authentication
- Support tickets
- Live chat

### **Admin Side:**
- User management
- Balance adjustments
- Fee configuration
- Transaction monitoring
- Support ticket system
- Live chat management
- Audit logs

### **Technical:**
- React + TypeScript
- Tailwind CSS
- PWA support
- iOS/Android ready
- Cross-platform storage
- Beautiful UI

---

## 📊 Technology Stack

- **Frontend:** React 18 + TypeScript
- **Styling:** Tailwind CSS v4
- **Build:** Vite 5
- **UI Components:** Shadcn/ui
- **Icons:** Lucide React
- **Charts:** Recharts
- **Native:** Capacitor 6
- **PWA:** Vite PWA Plugin
- **Storage:** Cross-platform (web + native)
