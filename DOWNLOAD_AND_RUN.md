## 🆘 Quick Troubleshooting

**Problem:** `npm install` fails  
**Fix:** Update Node.js to v18+ from https://nodejs.org

**Problem:** Port 5173 in use  
**Fix:** `npm run dev -- --port 3000`

**Problem:** Module not found  
**Fix:** Delete `node_modules`, run `npm install` again

**Problem:** Can't find files  
**Fix:** Check `/COMPLETE_FILE_LIST.md` - all 105+ files listed
